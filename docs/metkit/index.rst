Metkit
======

:Version: |version|

.. warning::
   These documentation pages are a work in progress.

Metkit is part of `ECMWF <https://www.ecmwf.int>`__'s meteorological software
stack. It provides tools for handling meteorological data, most notably the
parsing, expansion and manipulation of `MARS
<https://www.ecmwf.int/en/forecasts/access-forecasts/access-archive-datasets>`__
language requests.

This section documents the main C++ library.
