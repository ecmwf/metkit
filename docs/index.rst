:ref:`Metkit <Metkit_Introduction>` is part of `ECMWF
<https://www.ecmwf.int>`__'s meteorological software stack. It provides tools
for handling meteorological data, most notably the parsing, expansion and
manipulation of `MARS <https://www.ecmwf.int/en/forecasts/access-forecasts/access-archive-datasets>`__
language requests.

:ref:`pymetkit <PyMetkit_Introduction>` is the Python interface to Metkit,
providing a thin, idiomatic Python layer over the Metkit library installed on
your system.
